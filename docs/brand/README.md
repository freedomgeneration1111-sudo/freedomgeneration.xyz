## Raster files
PNG files preserve transparency.
WebP files use lossless WebP so edges/text remain crisp.

## SVG files
The SVG files are genuine path-only vector traces. They contain no embedded bitmap
and no `<image>` wrapper. Because the approved artwork originated as raster/generated
art rather than native vector geometry, the SVG traces necessarily simplify the
subtle shading into layered vector color regions.

For pixel-faithful website display, use the PNG or WebP files.
For infinitely scalable flat/vector use, use the SVG files.
A future hand-built native vector master can replace the traced SVGs without changing
the approved raster identity.

## Favicon
`favicon.ico` contains multiple embedded sizes for browser compatibility.
`fg-favicon.svg` is the scalable favicon.
`apple-touch-icon.png` is 180×180.
